# 會員成長體系

YesFi 會員體系以**會員積分（Y積分）**&#x70BA;核心成長指標。用戶在平臺內完成的連接錢包、交易、簽到、邀請好友等行為，均會按規則轉化為 Y 積分。Y 積分持續累積，決定用戶的會員等級；會員等級決定用戶可獲得的權益水平。

***

### 一、體系運行邏輯

會員體系的運行遵循以下閉環：

{% hint style="info" icon="rotate" %}
**完成任務 → 獲得 Y 積分 → Y 積分累積升級 → 等級解鎖權益 → 權益以代金券、盲盒等形式發放 → 用戶使用權益繼續參與交易**
{% endhint %}

體系遵循以下三項基本原則：

1. **Y 積分永久有效**：Y 積分為累計製成長資產，不因交易盈虧、代金券消費或權益核銷而減少。
2. **等級只升不降**：會員等級一經達成即長期保留，不會因階段性不活躍而下調。
3. **等級與權益強綁定**：等級越高，可獲得的代金券面額、發放頻率及盲盒中獎概率相應提升。

***

### 二、Y 積分獲取方式

Y 積分的獲取來源覆蓋用戶在平臺內的主要行為，共分為五類：

| 任務類別      | 說明                                     |
| --------- | -------------------------------------- |
| 新手任務      | 覆蓋連接錢包、首次充值、首次交易、首次購買保險、完善資料、添加自選等首次行為 |
| 交易與資金使用任務 | 覆蓋保險購買、日常交易、單日多筆交易、連續交易日、大額充值留存等持續性行為  |
| 活躍與邀請任務   | 覆蓋每日簽到、連續簽到、邀請好友完成首充/首單及持續活躍           |
| 交易反饋任務    | 針對連續盈利給予正向激勵，針對單筆或連續虧損提供相應的權益補償        |
| 活動與節日任務   | 覆蓋週年慶、節日、生日及限時活動期間的指定交易行為              |

部分任務示例如下：

| 任務名稱     | 完成條件                      | 獲得積分       |
| -------- | ------------------------- | ---------- |
| 首次連接錢包   | 成功連接或創建錢包                 | 50 Y積分     |
| 首次充值     | 單次充值金額 ≥ 100 USDC         | 500 Y積分    |
| 首次交易     | 完成任一玩法下單筆金額 ≥ 10 USDC 的交易 | 500 Y積分    |
| 首次購買保險   | 完成一筆帶保險的合約交易並結算           | 1000 Y積分   |
| 每日簽到     | 當日完成簽到                    | 1 Y積分/日    |
| 邀請好友完成首充 | 被邀請人完成首次充值                | 1000 Y積分/人 |

### 三、會員等級體系

YesFi 會員等級採用 V1–V40 非線性成長結構，劃分為五個階梯：

| 階梯             | 等級區間    | 用戶階段   |
| -------------- | ------- | ------ |
| 青銅（Bronze）     | V1–V5   | 破冰期    |
| 白金（Platinum）   | V6–V15  | 活躍養成期  |
| 黑金（Black Gold） | V16–V25 | 核心用戶期  |
| 鑽石（Diamond）    | V26–V35 | 長期留存期  |
| 神諭（Oracle）     | V36–V40 | 高階榮譽用戶 |

等級成長節奏分為三個階段：

* **前期（V1–V10）**：晉升門檻較低，用戶可通過完成新手任務在短時間內連續升級；
* **中期（V11–V30）**：晉升需依託持續交易、簽到與活動參與，權益同步逐步提升；
* **後期（V31–V40）**：晉升門檻顯著提高，主要面向長期活躍及高貢獻用戶，體現等級稀缺性。

***

### 四、會員權益體系

會員權益統一以以下三類形式發放：

* **期權代金券**：用於抵扣期權交易相關費用；
* **合約保險代金券**：用於抵扣合約保險保費；
* **盲盒**：內含上述兩類代金券的組合，具體權益價值由概率決定。

會員等級不改變基礎費率結構，但會影響以下方面：權益發放頻率、單張代金券面額、券種類型配比，以及盲盒中開出較高面額權益的概率。

各階段權益特徵如下：

| 階段   | 等級區間    | 權益特徵                              |
| ---- | ------- | --------------------------------- |
| 基礎段  | V1–V5   | 以小額期權代金券為主，配少量保險代金券，盲盒發放頻次較低      |
| 成長段  | V6–V15  | 代金券面額逐步提升，期權與保險代金券並重，盲盒發放頻次提高     |
| 高價值段 | V16–V40 | 以中高面額代金券為主，盲盒發放頻次明顯提升，高面額權益出現概率提高 |

權益按週期性發放，等級越高，單期可獲得的權益總價值越高。

***

### 五、其他體系設計

* **交易反饋機制**：用戶連續實現盈利時，可獲得相應的積分或權益加成；發生單筆較大虧損或連續虧損時，平臺將發放保險代金券作為補償，用於降低用戶後續交易成本。
* **迴流激勵機制**：用戶在一段時間無交易行為後，若重新完成一筆真實交易，將獲得專屬迴歸權益包。
* **邀請激勵機制**：邀請獎勵不僅覆蓋好友完成首充、首單，被邀請人後續保持長期活躍，邀請人還可獲得額外的長期陪伴權益。
* **權益凍結與解凍規則**：用戶連續 14 天無核心行為，其日常權益將被凍結；用戶完成任意一筆真實交易後，權益自動解凍。凍結機制不影響用戶已累積的 Y 積分及已達成的會員等級。

***

### 六、總結

YesFi 會員體系以 Y 積分為唯一成長指標，用戶在平臺內的連接、交易、簽到、邀請等行為均可轉化為積分累積。積分決定等級，等級決定權益水平；權益以代金券及盲盒形式發放，用於支持用戶在平臺內的持續交易與體驗。Y 積分永久有效，會員等級只升不降，用戶的成長成果將被長期保留。
