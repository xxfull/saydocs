# Which assets can I deposit?

YesFi currently supports deposits of **USDC** only.

| Deposit asset | Supported network |
| ------------- | ----------------- |
| USDC          | Ethereum          |
| USDC          | BSC               |
| USDC          | Base              |
| USDC          | Arbitrum          |

Not all digital assets can be transferred to YesFi. Before depositing, confirm that your selected network matches a supported network.

{% hint style="warning" %}
Assets sent through an unsupported or incorrect network may not arrive.
{% endhint %}
